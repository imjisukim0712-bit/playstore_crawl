플레이스토어 게임 매출 리포트

playstore_crawl이 매일 수집한 구글 플레이 대한민국 매출 순위(게임 부문 1~100위)를 바탕으로 한 시장조사 리포트입니다. GitHub Actions가 매일 스토어를 다시 수집하고 이 페이지를 자동으로 갱신합니다.
